# Dashboard

**Open `retail_dashboard.html` in any browser.** It is one self-contained file (no server, no internet, no installs).

| Tab | What it shows |
|-----|---------------|
| Overview | Gross sales, headline KPIs, monthly sales, new vs returning customers, key findings |
| Retention | Cohort heatmap, 90-day repeat rate, new customers per month (UK / non-UK) |
| Segments | RFM segments by customers vs revenue, revenue concentration curve, who is slipping away |
| Churn risk | Churn by days silent, back-tested early-warning rules, top-value customers to contact first |
| Actions | Four sized recommendations with low / mid / high scenarios |

Features: hover tooltips on every chart, a **Table view** toggle on every chart, and a light / dark / auto theme button.

## How it is built
- `template.html` holds the layout and chart code (plain HTML, CSS and SVG; no libraries).
- `notebooks/08_build_dashboard.ipynb` prepares the numbers from `data/processed/` and writes `retail_dashboard.html` with the data embedded.
- To refresh after changing an analysis notebook, re-run that notebook, then notebook 08.

## Tableau
**`tableau/retail_dashboard.twbx` is the Tableau workbook to present or share.** It has the same five dashboards (Overview, Retention, Segments, Churn risk, Actions). It was generated by notebook 09, then opened and re-saved in Tableau with hand edits (two year-over-year line charts were added to the Overview). It carries its own data (88 KB), so it opens on any computer with Tableau, without the project folder.

**`tableau/retail_dashboard_generated.twb` and `.twbx`** are what notebook 09 writes. Re-running the notebook only rewrites these two files and never touches `retail_dashboard.twbx`. The generated `.twb` stores absolute paths to the CSVs in `tableau/data/` and only works from this project folder (if you move the project, use Data > Edit Data Source > Replace); the generated `.twbx` has no such limit.

- It is generated by `notebooks/09_build_tableau_workbook.ipynb` (data from notebook 08). The XML structure follows the sample workbook that ships with Tableau Desktop.
- It was opened and checked in Tableau Desktop 2026.3 **Free Edition**: all five dashboards load, and the tiles, heatmap, bar charts, line chart and tables render. Each dashboard and each chart type was viewed in a screenshot. Not directly seen: the small orange "Overseas" segments at the bottom of the new-customers-by-region chart (they use the same setup as the existing-vs-new chart, where the orange segments do show), and the very bottom of the Overview findings text.
- **Design:** each dashboard has a navy header banner with a one-line takeaway (for example "Silence is the signal: contact customers quiet for 90+ days, biggest first"), a light gray page with white bordered cards, a row of headline tiles on top, and a plain-language insight card where a chart needs context. The colour pair is Tableau's default blue (main series, existing, domestic) and orange (new, overseas, emphasis).
- Free Edition ignores custom colour palettes, so charts use Tableau's default blue and orange and the heatmap uses Tableau's default green-blue ramp.
- The tile numbers, axis percentages and chart legends are written into the data and the sheet titles, because Tableau applies the viewer's regional number separators and custom number formats were not reliable.

`tableau_data/` and `tableau_build_guide.md` are the older manual route: tidy CSVs and step-by-step instructions to rebuild the pages by hand if you prefer.

## Notes
- Scenario figures on the Actions tab are assumptions, not forecasts.
- Customer IDs are the anonymised numbers from the public dataset.
